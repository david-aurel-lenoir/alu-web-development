# SmileSchool

A static landing page for **SmileSchool**, a fictional online platform where people learn to smile from award-winning "pros". The page is built with plain HTML and is meant as a front-end practice project.

## Page sections

- **Header**: logo and navigation (Courses, Pricing, Login)
- **Hero banner**: "Get schooled" headline with a *Register for free* button
- **Learn from the pros**: four instructor cards with photo, name, and award
- **Testimonial**: a quote from a student with photo and job title
- **Most popular tutorials**: four tutorial cards (Diagonal, Sad, Natural, Happy Smile) with author, star rating, and duration
- **Free membership**: four benefit blocks and a second *Register for free* button
- **F.A.Q.**: four questions in two columns
- **Footer**: logo, social links (Facebook, Twitter, Instagram), and copyright

## Project structure

```
.
├── index.html
├── logo.png
├── star.png
├── smile-icon.png
├── facebook.png / twitter.png / instagram.png
└── instructor, tutorial and testimonial images (.jpg)
```

## Getting started

1. Put `index.html` and the image files in the same folder.
2. Open `index.html` in any web browser.

No build tools or dependencies are needed.
